# Mars-roveren Perseverance – dansk GitHub Pages-projekt

## Udgivelse
1. Opret et GitHub-repository.
2. Upload `index.html`, `style.css`, `app.js` og `README.md` til roden.
3. Gå til Settings → Pages.
4. Vælg Deploy from a branch, `main` og `/ (root)`, og gem.

## Kodeeditor
Editoren bruger en begrænset Python-lignende fortolker uden ekstern runtime. Den understøtter `rover.forward(tal)`, `rover.left(tal)`, `rover.right(tal)`, kommentarer og `for i in range(4):` med indrykkede kommandoer. Den er ikke en fuld Python-implementering. Løkker, indlejring og antal instruktioner er begrænset for at undgå browserfrysning.

## Missioner
Alle syv missioner har danske beskrivelser, mål, testvejledning og en enkelt relevant startlinje. Testknappen giver vejledende feedback; den erstatter endnu ikke en fuld geometrisk kontrol af hver enkelt bane. Projektet er en selvstændig læringsprototype og ikke en pixel-for-pixel-kopi af 101 Computing.
